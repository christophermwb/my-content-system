# my-content-system

## Project Overview
A content management system with AI-assisted workflows.

## Guidelines
- Follow tone and style guidelines defined in skills/tone-checker.md
- Use memory.md to track project context and decisions
- Skills in the skills/ directory define reusable AI workflows

## File Structure
- `CLAUDE.md` — project instructions for Claude
- `memory.md` — persistent project memory and context
- `skills/tone-checker.md` — skill for checking content tone
- `skills/learn.md` — skill for learning and updating project knowledge
