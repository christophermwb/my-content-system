# Project Memory

## Key Decisions

- **2026-03-09**: Adopted Intuit Content Design Guidelines as the governing standard for this project. Source: contentdesign.intuit.com (compiled PDF, July 2025). All rules encoded in CLAUDE.md.

## Conventions

- Voice: Warm, Confident, Genuine
- Readability target: 5th–8th grade
- Paragraphs: 1–2 sentences max
- Dashes: em dash (—) only for thought separation
- Authentication: "sign in / sign out" — never "log in / log out"
- Superlatives: banned unless backed by cited data
- Celebrations: only for genuine customer milestones, not routine actions
