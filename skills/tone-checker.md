# Skill: Tone Checker

## Purpose
Review content against the Intuit Content Design Guidelines enforced in this project.

## Trigger
Use when asked to check, review, or edit the tone or quality of any content.

## Steps

1. Read the content carefully
2. Check it against each rule category below
3. Flag every violation with the exact phrase and the rule it breaks
4. Suggest a specific rewrite for each flagged item
5. Give an overall verdict: **On-tone** / **Needs work** / **Off-tone**

---

## Checklist

### Voice & Tone
- [ ] Does it sound warm, confident, and genuine — not stiff or corporate?
- [ ] Does it avoid telling the customer how they'll feel? ("You're going to love..." → flag it)
- [ ] If something is challenging, does it acknowledge that honestly?
- [ ] Does "don't worry" appear? If so — is the situation genuinely low-stakes? If not, cut it.
- [ ] Does it put customer benefit ahead of business goals?
- [ ] Is it free of manipulation, overpromising, or upsell pressure?

### Superlatives — flag all of these
- [ ] best, most, top, fastest, ultimate, premier, most-trusted, world-class, #1, amazing, high-quality, great (when "good" would do)
- Exception: superlatives are OK if followed by a cited, verifiable source

### Brevity & Readability
- [ ] Are sentences short? (aim for 1–2 per paragraph)
- [ ] Are there long words (8–9 letters) that could be replaced with shorter ones?
- [ ] Is the key message front-loaded?
- [ ] Is the reading level approximately 5th–8th grade?
- [ ] Is "simple" or "simply" used anywhere? (flag it — simplicity is subjective)

### Word & Phrase Flags
- [ ] "log in" / "log on" / "log out" → replace with "sign in" / "sign out"
- [ ] "sign into" → replace with "sign in to"
- [ ] "since" used for cause-and-effect → replace with "because"
- [ ] "due to the fact that" → never acceptable
- [ ] "sorry" used as filler → only OK when something was genuinely broken
- [ ] "above" or "below" as directional cues → replace with specific element names
- [ ] "utilize" → replace with "use"
- [ ] "a.m." / "p.m." → replace with "AM" / "PM"
- [ ] "bank statement" → replace with "account statement"
- [ ] "ACH" in consumer-facing copy → prefer "bank transfer" unless legal requires ACH
- [ ] "401K" or "401k" → replace with "401(k)"

### Formatting
- [ ] Are en dashes (–) or hyphens (-) used to separate thoughts? → replace with em dash (—)
- [ ] Are ampersands (&) used in body text? → spell out "and" (OK in nav/table headers)
- [ ] Does angle bracket notation appear (Settings > Account)? → rewrite as "Go to Settings, then select Account"
- [ ] Is ALL CAPS used for anything other than established acronyms?
- [ ] Are there multiple asterisks in one sentence? → flag accessibility issue

### Celebrations (if reviewing a celebration/success message)
- [ ] Is this celebrating a genuine customer milestone? If it's a routine action → downgrade to a success message
- [ ] Does it tell the customer how to feel ("Time to celebrate!")? → flag it
- [ ] Is it condescending for the situation? ("Right on! You signed in!") → flag it

---

## Output Format

**Flagged items:**
- [Quote] → Rule broken → Suggested rewrite

**Overall verdict:** On-tone / Needs work / Off-tone

**Summary:** One sentence on the biggest issue to fix.
